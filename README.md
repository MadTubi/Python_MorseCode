# Python_MorseCode
Text File Message Encoder & Decoder

A beginner-friendly Python project that allows users to encode and decode messages using a key stored in a text file (Key.txt).  
The program uses dictionaries to translate letters into symbols and symbols back into letters, with a simple menu to select between  
encoding, decoding, or exiting the program. Messages are read from and processed using text files, providing hands-on practice  
with Python file handling, dictionaries, loops, and conditional statements.
